使用说明与隐私

① 选择腾讯云或 OpenAI，输入原来的接口密码并检查连接。② 选择本地文件和识别语言。③ 开始识别，完成后导出 SRT，导入你的听力播放器即可。

勾选自动转音频后，只上传提取的音频，原视频用于本机预览。普通 M4A 音轨直接分段，其他支持的音频格式会在本机解码为 WAV 后分段；长音频在手机上可能较耗内存，建议用电脑。分段处可能截断连续语句，完成后可检查修改。特殊编码或分片视频可能不支持。文件会临时上传云端供所选服务读取，成功查询到完成或失败状态时尝试删除。若中途关闭网页，请在 23 小时内回来继续查询，以便取回结果和触发清理。OpenAI 完成识别后立即尝试删除媒体文件，结果回执在取回结果后清理；提交中断时可用“继续查询上次任务”恢复。视频保留在本机的预览不等于云端上传。

“暂停查询”只停止网页轮询，不会撤销腾讯云已提交的识别任务或相关费用。上传中停止会中断上传。点击“余额 / 额度与充值”的快捷入口可进入官方后台查看，网页不读取或推测实际余额。

OpenAI 配置：在 Supabase 项目 Secrets 中添加 OPENAI_API_KEY，值填你自己的 OpenAI API 密钥。不要写进 HTML；此页只填写原来的接口密码。检查连接只确认配置，不验证余额，也不提交识别任务。

OpenAI 当前采用 whisper-1 获取真实时间轴。官方计划于 2027年2月26日停用该模型，届时需要更新后台识别方案，不能保证永久免维护。
